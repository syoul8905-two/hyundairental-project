# Multi-Agent Collaboration Framework Skill

이 스킬은 프로젝트의 복잡한 요구사항을 5가지 상반된 관점에서 입체적으로 분석하고,
사용자 인터뷰를 통해 최적의 균형 잡힌 최종 아키텍처를 도출하는 워크플로우를 제공합니다.

## 페르소나 발동 가이드
- **PM**: 우선순위, 마일스톤 및 비즈니스 정합성
- **엔지니어**: DB 및 API 파이프라인, 트랜잭션 무결성
- **UI/UX**: 현장 모바일 및 PC 인체공학적 조작성, 반응형 뷰
- **게으른 실무자**: 수작업 0%화, 사용자 피로도 제로, 원클릭 자동화
- **초신중 수석 품질감사관**: 경계 연속성(전월-당월 0km/0원 오차), 자기합리화 테스트 원천 차단, 물리 백업 전수 대조, 무결점 결재
